# 🎙️ Innova AI

**AI-powered voice agent that you can plug straight into your website to handle conversations with your visitors and customers automatically.**

🚀 [Live Demo](https://innova-ai-7tee.onrender.com) &nbsp;|&nbsp; 💻 [GitHub Repo](https://github.com/Anshi7300/Innova-AI)

</div>

---

## ✨ Features

- 🗣️ AI-powered voice agent for real-time conversations
- 🌐 Easy to embed and use on any website
- ⚡ Fast, responsive interactions powered by AI API integration
- 🗄️ Persistent data storage with MongoDB
- 🔐 Configurable via environment variables for easy deployment

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js |
| Backend | Node.js, Express.js |
| Database | MongoDB |
| AI Integration | AI API |
| Deployment | Render |

---

## 🚀 How It Works

1. User visits a website with Innova AI embedded
2. User speaks or types to the voice agent
3. The AI processes the input and generates a response in real time
4. The agent replies back to the user, keeping the conversation going

## 📦 Installation

**1. Clone the repository**
```bash
git clone https://github.com/Anshi7300/Innova-AI.git
cd Innova-AI
```

**2. Backend setup**
```bash
cd server
npm install
```

**3. Frontend setup**
```bash
cd client
npm install
```

**4. Setup environment variables**

Create a `.env` file in the server directory:
```env
PORT=5000
MONGO_URI=your_mongodb_connection
AI_API_KEY=your_api_key
```

**5. Run the project**
```bash
# in /server
npm start

# in /client
npm start
```
